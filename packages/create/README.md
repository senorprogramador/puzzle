# @puzzle-ui/create

Create React applications with Puzzle UI.

## Requirements

- Node.js >= 20.19
- npm or Bun

## Usage

With npm:

```bash
npx @puzzle-ui/create
```

With Bun:

```bash
bunx @puzzle-ui/create
```

## Supported frameworks

- Next.js
- TanStack Start
- Basic React (Vite + TypeScript)

## Features

- Interactive project setup
- Automatic kebab-case project names
- Framework scaffolding using official CLI tools
- Automatic Puzzle UI installation
- Automatic Puzzle Theme configuration
- React 19 compatibility
