# Website-generation workflow

This short entry point is retained for existing links. Use the complete
[website planning engine](../website/README.md) for the 15-phase workflow,
working templates, decision rules, and pre-implementation checklist.

The planning engine separates planning (phases 1–10), implementation
(11–12), and quality assurance and delivery (13–15). It does not require using
every Puzzle package or building a website generator.

For framework support, consult the
[compatibility matrix](../frameworks/compatibility.md); for component choices,
the [component-selection guide](../reference/component-selection.md); and for
data classification, the [data architecture guide](../reference/data-architecture.md).
