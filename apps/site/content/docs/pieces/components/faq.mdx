`FAQSection` displays question and answer data using the UI Accordion primitive. Each item has a stable ID, question, and answer. Category grouping, searchable text, and an empty state are optional.

<Badge content="Stable" color="primary" /> **API maturity: Stable.** The documented API is covered by package tests and is intended to remain backward-compatible within a major version. This is an API commitment, not a guarantee of production readiness in every application.

## Installation

```tsx
import { FAQSection, type FAQItem } from "@puzzle-ui/pieces";
```

## Variant previews

Disclosures support keyboard activation and either single or multiple expansion. Search filters the current collection locally; it does not call an external search service.

## API

| Prop | Type | Description |
| --- | --- | --- |
| `variant` | `FAQVariant` | Selects one of twelve FAQ presentations; defaults to `accordion`. |
| `items` | `readonly FAQItem[]` | Questions with stable `id`, `question`, and `answer`. |
| `FAQItem.category` | `string` | Category label for grouped/categorized variants. |
| `FAQItem.searchText` | `string` | Optional text included in searchable filtering. |
| `FAQItem.featured` | `boolean` | Adds a featured label to selected items in the `featured` variant. |
| `expandMode` | `"single" \| "multiple"` | Accordion expansion mode; defaults to `single`. |
| `searchLabel` / `searchPlaceholder` | `string` | Visible search label and placeholder. |
| `emptyState` | `ReactNode` | Optional custom empty or no-results content. |
| Shared section props | `SectionRootProps` and heading props | Semantic root, theme, native attributes, heading, actions, and children. |


### Required and default values

Requiredness follows the exported TypeScript type. A dash means no component-level default is applied; variant-specific requirements are described in the API table above.

| Prop | Required | Default |
| --- | --- | --- |
| `variant` | No | `"accordion"` |
| `items` | Yes | — |
| `expandMode` | No | `"single"` |
| `searchLabel` | No | `"Search questions"` |
| `searchPlaceholder` | No | `"Search"` |
| `emptyState` | No | — |
## Usage

```tsx
<FAQSection
  variant="searchable"
  title="Frequently asked questions"
  items={[
    {
      id: "delivery",
      question: "When will my order arrive?",
      answer: "Delivery usually takes two business days.",
      searchText: "shipping arrival",
    },
  ]}
/>
```

An empty collection shows a default status message unless `emptyState` is provided. In categorized mode, category links target IDs generated for that section instance.

## Accessibility

Accordion triggers and panels use UI Accordion semantics and keyboard behavior. Search has a visible label, and empty results are announced with a status region. Keep item IDs unique and questions concise.

## Customization

Use the component's `className` and documented slots to adapt the composition. Prefer a caller-provided `ReactNode` for media, actions, or controls rather than adding domain behavior to the section.

```tsx
import type { ComponentProps } from "react";
import { FAQSection } from "@puzzle-ui/pieces";

type FAQSectionProps = ComponentProps<typeof FAQSection>;

export function CustomizedSection(props: FAQSectionProps) {
  return <FAQSection {...props} className={[props.className, "brand-section"].filter(Boolean).join(" ")} />;
}
```

## Responsive behavior

Use the preview device selector to review mobile, tablet, and desktop widths. The built-in variant controls section structure; ensure application-provided media, form controls, and children can shrink or wrap without horizontal overflow. Use the existing responsive breakpoints in scoped CSS when the consuming layout needs a product-specific adjustment.

## Theme support

The section consumes semantic variables from `@puzzle-ui/theme` and inherits active or scoped themes. Wrap the application with `Theme`, and use semantic roles such as text, surface, border, and primary for local overrides. Avoid hard-coded colors, spacing, radii, and shadows.

```css
.brand-section {
  color: var(--puzzle-color-text);
  background: var(--puzzle-color-surface);
  border-color: var(--puzzle-color-border);
}
```

## Composition

Compose this section with the UI primitives named in its API and use the documented slots for consumer-owned controls or media. Keep data fetching, routing, validation, permissions, and persistence in the application. The `children` slot is intended for additional content that belongs with this section, not as a substitute for its typed data model.

## TypeScript example

The package exports this component from its root. Derive a wrapper's exact prop type from the public component rather than widening it:

```tsx
import type { ComponentProps } from "react";
import { FAQSection } from "@puzzle-ui/pieces";

type FAQSectionProps = ComponentProps<typeof FAQSection>;

export function SectionWrapper(props: FAQSectionProps) {
  return <FAQSection {...props} />;
}
```
