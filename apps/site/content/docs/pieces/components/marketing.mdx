Puzzle Pieces provides focused section compositions for common marketing and conversion tasks. Each component renders semantic content from consumer-provided data, uses Puzzle UI section and interaction primitives, and leaves routing, forms, persistence, and product logic to the consuming application.

<Badge content="Beta" color="primary" /> **API maturity: Beta.** These APIs are new and may evolve before reaching Stable. Use the individual references for the current variant list, props, and accessibility behavior.

## Shared design

All ten sections accept the shared semantic root and heading props from `SectionRootProps`, including `as`, native and ARIA attributes, `className`, `style`, and the UI `Section` theme, padding, and width options. The common `eyebrow`, `title`, `titleAs`, `description`, `alignment`, `actions`, and `children` props compose an optional `SectionHeader` with the section-specific content. Empty header slots and empty item collections are omitted.

Variants are family-specific string unions rather than one universal preset API. Some variants select a different content composition or native interaction, while others apply a focused layout treatment to the same semantic content. Actions, media, logos, icons, and custom children remain consumer-provided React nodes.

## Accessibility and responsive behavior

The sections use mobile-first layouts, theme variables, semantic lists and tables, native form controls, and the existing UI Accordion, Tabs, Carousel, Button, and Rating components where those interactions fit. Carousel wrappers support arrow-key navigation; FAQ disclosures and feature tabs retain their UI primitive keyboard behavior. Comparison tables remain in a labeled, keyboard-scrollable viewport on narrow screens. Animated statistics respect `prefers-reduced-motion`, and logo marquees do not auto-animate.

Provide accurate logo alt text and media alternatives. Keep heading levels appropriate to the page, supply stable unique item IDs, and make consumer-provided action labels descriptive. Forms, links, event tracking, countdown business rules, and data fetching are not supplied by these presentation components.

## Installation

Import sections and their item/variant types from the package root:

```tsx
import {
  AnnouncementSection,
  FAQSection,
  FeaturesSection,
  type FAQItem,
  type FeaturesVariant,
} from "@puzzle-ui/pieces";
```
