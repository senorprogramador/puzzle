Feedback compositions provide presentation primitives and callbacks; applications remain responsible for notification delivery and action outcomes.

<Badge content="Beta" color="info" /> **API maturity: Beta.** These compositions are new and may evolve based on feedback.

## Installation

```tsx
import {
  ConfirmAction,
  ErrorStatePanel,
  NotificationItem,
  NotificationList,
} from "@puzzle-ui/pieces";
```

## Confirming an action

`ConfirmAction` uses Puzzle's `Dialog` and `Button` components. The callback runs only after explicit confirmation; application code owns errors and persistence.

```tsx
<ConfirmAction
  triggerLabel="Delete project"
  title="Delete this project?"
  description="This action cannot be undone."
  confirmLabel="Delete"
  onConfirm={deleteProject}
/>
```

## Error recovery

`ErrorStatePanel` composes Puzzle's error `Alert` with an optional recovery action.

<Preview
  code={`\
<ErrorStatePanel
  title="We couldn't load this view"
  description="Your work is safe. Check your connection, then try again."
  action={<Button>Try again</Button>}
/>
`}
>
  <ErrorStatePanel
    title="We couldn't load this view"
    description="Your work is safe. Check your connection, then try again."
    action={<Button>Try again</Button>}
  />
</Preview>

## Accessibility and responsive behavior

- Notification collections use list semantics and timestamps can include machine-readable `dateTime` values.
- Dismiss buttons have accessible names.
- Confirmation uses the Puzzle Dialog's labelled modal and keyboard dismissal behavior.
- Error messages use the Puzzle Alert's assertive semantics.
- Provide concise labels and avoid relying on color alone to communicate status.

## API

| Component | Props |
| --- | --- |
| `NotificationItem` | `title` (required), `description`, `timestamp`, `dateTime`, `href`, `unread`, `onDismiss`, `dismissLabel`, `className` |
| `NotificationList` | `items` (required; each has `id` and `NotificationItem` props), `label`, `emptyState`, `className` |
| `ConfirmAction` | `triggerLabel`, `title`, `confirmLabel`, `onConfirm` (required), `description`, `cancelLabel`, `confirmVariant`, `className` |
| `ErrorStatePanel` | `title` (required), `description`, `action`, `className` |
