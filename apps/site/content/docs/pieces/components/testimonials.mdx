`TestimonialsSection` renders customer statements with required attribution. Items require a stable `id`, quote, and author; role, organization, avatar, company logo, rating, media, featured styling, and caller-provided footer metadata are optional.

<Badge content="Beta" color="primary" /> **API maturity: Beta.**

## Installation

```tsx
import { TestimonialsSection, type TestimonialItem } from "@puzzle-ui/pieces";
```

## Variant previews

## API

| Prop | Type | Description |
| --- | --- | --- |
| `variant` | `TestimonialsVariant` | Selects one of fourteen testimonial compositions; defaults to `grid`. |
| `items` | `readonly TestimonialItem[]` | Attributed quote data. |
| `TestimonialItem.quote` | `ReactNode` | Required quote content. |
| `TestimonialItem.author` | `string` | Required author name. |
| `TestimonialItem.rating` | `number` | Optional read-only rating. |
| `TestimonialItem.avatar` / `companyLogo` | `ReactNode` | Optional consumer-provided identity nodes. |
| `TestimonialItem.media` | `ReactNode` | Optional image, video, or other media. |
| `TestimonialItem.metadata` | `ReactNode` | Optional caller-provided footer metadata, such as a date and source. |
| `carouselLabel` | `string` | Accessible carousel name; defaults to `Customer testimonials`. |
| Shared section props | `SectionRootProps` and heading props | Semantic root, theme, native attributes, heading, actions, and children. |


### Required and default values

Requiredness follows the exported TypeScript type. A dash means no component-level default is applied; variant-specific requirements are described in the API table above.

| Prop | Required | Default |
| --- | --- | --- |
| `variant` | No | `"grid"` |
| `items` | Yes | — |
| `carouselLabel` | No | `"Customer testimonials"` |
## Usage

```tsx
<TestimonialsSection
  variant="carousel"
  title="What customers say"
  items={[
    {
      id: "riley",
      quote: "The team can focus on work that matters.",
      author: "Riley Chen",
      role: "Product lead",
      organization: "Acme",
      rating: 5,
    },
  ]}
/>
```

The quote is rendered as a blockquote with attribution in its footer. Supply alternatives for meaningful media and ensure any consumer-provided avatar content does not repeat the visible author name.

## Accessibility

Each quote is semantically attributed. Carousel controls have accessible names and support both buttons and arrow-key navigation. Ratings are read-only and labeled. Keep the author and organization text available even when logos or avatars are supplied.

## Customization

Use the component's `className` and documented slots to adapt the composition. Prefer a caller-provided `ReactNode` for media, actions, or controls rather than adding domain behavior to the section.

```tsx
import type { ComponentProps } from "react";
import { TestimonialsSection } from "@puzzle-ui/pieces";

type TestimonialsSectionProps = ComponentProps<typeof TestimonialsSection>;

export function CustomizedSection(props: TestimonialsSectionProps) {
  return <TestimonialsSection {...props} className={[props.className, "brand-section"].filter(Boolean).join(" ")} />;
}
```

## Responsive behavior

Use the preview device selector to review mobile, tablet, and desktop widths. The built-in variant controls section structure; ensure application-provided media, form controls, and children can shrink or wrap without horizontal overflow. Use the existing responsive breakpoints in scoped CSS when the consuming layout needs a product-specific adjustment.

## Theme support

The section consumes semantic variables from `@puzzle-ui/theme` and inherits active or scoped themes. Wrap the application with `Theme`, and use semantic roles such as text, surface, border, and primary for local overrides. Avoid hard-coded colors, spacing, radii, and shadows.

```css
.brand-section {
  color: var(--puzzle-color-text);
  background: var(--puzzle-color-surface);
  border-color: var(--puzzle-color-border);
}
```

## Composition

Compose this section with the UI primitives named in its API and use the documented slots for consumer-owned controls or media. Keep data fetching, routing, validation, permissions, and persistence in the application. The `children` slot is intended for additional content that belongs with this section, not as a substitute for its typed data model.

## TypeScript example

The package exports this component from its root. Derive a wrapper's exact prop type from the public component rather than widening it:

```tsx
import type { ComponentProps } from "react";
import { TestimonialsSection } from "@puzzle-ui/pieces";

type TestimonialsSectionProps = ComponentProps<typeof TestimonialsSection>;

export function SectionWrapper(props: TestimonialsSectionProps) {
  return <TestimonialsSection {...props} />;
}
```
