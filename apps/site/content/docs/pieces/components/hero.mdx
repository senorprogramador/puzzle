# Heroes

Heroes are introductory sections that establish the visual identity of a page.

Puzzle Pieces provides a flexible Hero component and a collection of specialized presets. All presets share the same underlying implementation, making them easy to customize without maintaining separate layouts.

## Installation

Import the Hero components from Puzzle Pieces:

```tsx
import {
  Hero,
  SplitHero,
  CenteredHero,
  FullScreenHero,
  ImageHero,
  VideoHero,
} from "@puzzle-ui/pieces";
```

## Components

| Component            | Description                      |
| -------------------- | -------------------------------- |
| Hero                 | Generic hero component           |
| SplitHero            | Text and media side by side      |
| CenteredHero         | Centered introduction            |
| FullScreenHero       | Full viewport introduction       |
| VideoHero            | Background video                 |
| ImageHero            | Background image with overlay    |
| MinimalHero          | Minimal introduction             |
| EditorialHero        | Editorial layout                 |
| AgencyHero           | Agency and consultancy websites  |
| ProductHero          | Product introductions            |
| SaaSHero             | SaaS product websites            |
| StoreHero            | Online stores and collections    |
| RestaurantHero       | Restaurants and hospitality      |
| AccommodationHero    | Hotels and holiday accommodation |
| PrintShopHero        | Printing businesses              |
| DashboardWelcomeHero | Dashboard introductions          |
| AppHero              | Web application introductions    |
| CampaignHero         | Campaign landing pages           |
| ComingSoonHero       | Pre-launch pages                 |
| SearchHero           | Search-oriented websites         |

## Media positioning

Control where media is displayed using mediaPosition.

| Value      | Description          |
| ---------- | -------------------- |
| left       | Media before content |
| right      | Media after content  |
| background | Media behind content |

## Height

Control the minimum height of the hero.

| Value    | Description                    |
| -------- | ------------------------------ |
| auto     | Content determines the height  |
| large    | Large introductory section     |
| viewport | Minimum height of the viewport |

<Preview
  code={`\
<Hero height="viewport" title="Welcome." />
`}
>
  <Hero height="viewport" title="Welcome." />
</Preview>

## Themes

Hero supports four theme configurations.

| Value    | Description                    |
| -------- | ------------------------------ |
| light    | Standard light appearance      |
| dark     | Dark appearance                |
| contrast | Contrasting surface appearance |
| brand    | Primary brand appearance       |

<Preview
  hideDevices={true}

`}
>
  <Hero theme="brand" title="Your brand, your experience." />
</Preview>

Hero consumes semantic Puzzle Theme tokens for its background, foreground, typography and spacing.

## Responsive behavior

Hero automatically adapts its layout to smaller screens.

- Split layouts become single-column layouts.
- Asymmetric layouts become single-column layouts.
- Media can move before content on mobile.
- Typography uses responsive sizing.
- Horizontal and vertical spacing adapt to available screen space.

Use reverseOnMobile to control the order of content and media.

<Preview
  code={`\
<Hero
  layout="split"
  reverseOnMobile
  title="Mobile-first experiences."
  media={<img src="https://images.unsplash.com/photo-1438761681033-6461ffad8d80?q=100&w=1024&h=1024&fit=crop&auto=format" alt="Example" />}
/>
`}
>
  <Hero
    layout="split"
    reverseOnMobile
    title="Mobile-first experiences."
    media={
      <img
        src="https://images.unsplash.com/photo-1438761681033-6461ffad8d80?q=100&w=1024&h=1024&fit=crop&auto=format"
        alt="Example"
      />
    }
  />
</Preview>

<Preview
  code={`\

### CSS customization

Hero uses regular CSS and semantic Puzzle Theme tokens.

The root element has the `puzzle-hero` class.

You can customize its appearance through CSS variables.

```css
.custom-hero {
  --puzzle-hero-padding-inline: var(--puzzle-space-8);
  --puzzle-hero-padding-block: var(--puzzle-space-16);
  --puzzle-hero-gap: var(--puzzle-space-10);
  --puzzle-hero-background: var(--puzzle-color-surface);
  --puzzle-hero-foreground: var(--puzzle-color-text);
}
```

You can also target individual elements using their class names.

| puzzle-hero                | Root element              |
| puzzle-hero\_\_inner       | Layout container          |
| puzzle-hero\_\_content     | Content container         |

| puzzle-hero\_\_overlay     | Background overlay        |

## Accessibility

Hero is designed to work with assistive technologies.

- Uses semantic section elements by default.
- Supports custom semantic elements through the as property.
- Supports configurable heading levels through titleAs.
- Supports accessible labels.
- Decorative background images have empty alternative text.
- Background videos are hidden from assistive technology.
- Background videos respect prefers-reduced-motion.
- Interactive content remains accessible through its original Puzzle components.

Always provide meaningful alternative text for informative images.

Use one primary heading per page where appropriate.
