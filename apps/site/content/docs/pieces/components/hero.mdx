Heroes are introductory sections that establish the visual identity of a page.

Puzzle Pieces provides a flexible Hero component and responsive presets for common layouts. All presets share the same implementation and can be customized with the Hero props.

<Badge content="Stable" color="primary" /> **API maturity: Stable.** The documented Hero and preset APIs are covered by tests and are intended to remain backward-compatible within a major version. This is an API commitment, not a guarantee of production readiness in every application.

## Installation

Import the Hero components from Puzzle Pieces:

```tsx
import {
  Hero,
  SplitHero,
  AsymmetricHero,
  CenteredHero,
  FullScreenHero,
  ImageHero,
  VideoHero,
} from "@puzzle-ui/pieces";
```

The former ProductHero, StoreHero, PrintShopHero and AppHero names remain
available as aliases of SplitHero. EditorialHero and SaaSHero alias
AsymmetricHero, and AccommodationHero aliases FullScreenHero. Use the canonical
component for new implementations.

SplitHero defaults to `height="large"`. Set `height="auto"` when the section
should take only the height required by its content.

## Responsive behavior

Hero adapts to mobile and tablet widths with responsive spacing, typography, and
media sizing. Split and asymmetric layouts stack on mobile and use side-by-side
columns at wider tablet and desktop widths.

- Split and asymmetric layouts use one column at mobile widths.
- At wider tablet and desktop widths, text and media render side by side.
- Tablet media uses a consistent landscape aspect ratio.
- Background-image heroes retain enough height for legible overlaid content.
- reverseOnMobile controls media and content order on mobile.

Use reverseOnMobile to control the order of content and media on mobile.

### CSS customization

Hero uses regular CSS and semantic Puzzle Theme tokens.

The root element has the `puzzle-hero` class.

You can customize its appearance through CSS variables.

```css
.custom-hero {
  --puzzle-hero-padding-inline: var(--puzzle-space-8);
  --puzzle-hero-padding-block: var(--puzzle-space-16);
  --puzzle-hero-gap: var(--puzzle-space-10);
  --puzzle-hero-background: var(--puzzle-color-surface);
  --puzzle-hero-foreground: var(--puzzle-color-text);
}
```

You can also target individual elements using their class names.

| Class                      | Element                   |
| -------------------------- | ------------------------- |
| puzzle-hero                | Root element              |
| puzzle-hero\_\_inner       | Layout container          |
| puzzle-hero\_\_content     | Content container         |
| puzzle-hero\_\_title       | Main heading              |
| puzzle-hero\_\_description | Description               |
| puzzle-hero\_\_eyebrow     | Eyebrow                   |
| puzzle-hero\_\_media       | Media container           |
| puzzle-hero\_\_background  | Background container      |
| puzzle-hero\_\_overlay     | Background overlay        |
| puzzle-hero\_\_actions     | Action container          |
| puzzle-hero\_\_search      | Search container          |
| puzzle-hero\_\_meta        | Supplementary information |

## Accessibility

Hero is designed to work with assistive technologies.

- Uses semantic section elements by default.
- Supports custom semantic elements through the as property.
- Supports configurable heading levels through titleAs.
- Supports accessible labels.
- Decorative background images have empty alternative text.
- Background videos are hidden from assistive technology.
- Background videos respect prefers-reduced-motion.
- Interactive content remains accessible through its original Puzzle components.

Always provide meaningful alternative text for informative images.

Use one primary heading per page where appropriate.

Hero itself is not a focusable control and adds no keyboard interaction. Tab
order comes from interactive descendants such as `actions` and `search`; make
those controls accessible by name and verify their keyboard behavior in your
application.

## Compatibility

The package targets React and React DOM 19. Hero does not depend on a router;
framework-specific and server-rendering compatibility are not guaranteed and
should be verified in the target application.

### Hero properties

`Hero` and the general presets accept `HeroProps`. `ImageHero` and `VideoHero`
also have exported specialized types that make their media source required:

```ts
type ImageHeroProps = Omit<HeroProps, "backgroundImage"> & {
  backgroundImage: string;
};

type VideoHeroProps = Omit<HeroProps, "backgroundVideo"> & {
  backgroundVideo: HeroVideoSource;
};
```

The other presets use `HeroProps`; the package does not export separate named
props types for each preset.

| Property         | Type              | Default |
| ---------------- | ----------------- | ------- |
| as               | ElementType       | section |
| titleAs          | ElementType       | h1      |
| id               | string            | -       |
| testId           | string            | -       |
| className        | string            | -       |
| contentClassName | string            | -       |
| mediaClassName   | string            | -       |
| style            | CSSProperties     | -       |
| layout           | HeroLayout        | split   |
| mediaPosition    | HeroMediaPosition | right   |
| alignment        | HeroAlignment     | start   |
| height           | HeroHeight        | auto    |
| theme            | HeroTheme         | light   |
| overlay          | HeroOverlay       | none    |
| contentWidth     | HeroContentWidth  | normal  |
| reverseOnMobile  | boolean           | true    |
| eyebrow          | ReactNode         | -       |
| title            | ReactNode         | -       |
| description      | ReactNode         | -       |
| media            | ReactNode         | -       |
| backgroundImage  | string            | -       |
| backgroundVideo  | HeroVideoSource   | -       |
| actions          | ReactNode         | -       |
| search           | ReactNode         | -       |
| meta             | ReactNode         | -       |
| children         | ReactNode         | -       |
| role             | AriaRole          | -       |
| ariaLabel        | string            | -       |
| ariaLabelledBy   | string            | -       |

### HeroLayout

```ts
type HeroLayout = "centered" | "split" | "full-width" | "asymmetric";
```

### HeroMediaPosition

```ts
type HeroMediaPosition = "left" | "right" | "background";
```

### HeroAlignment

```ts
type HeroAlignment = "start" | "center" | "end";
```

### HeroHeight

```ts

```

### HeroTheme

```ts
type HeroTheme = "light" | "dark" | "contrast" | "brand";
```

### HeroOverlay

```ts
type HeroOverlay = "none" | "subtle" | "strong" | "gradient";
```

### HeroContentWidth

```ts
type HeroContentWidth = "narrow" | "normal" | "wide" | "full";
```

```ts
type HeroVideoSource = {
  src: string;

  poster?: string;
```
