These families combine focused layouts with browser or application interactions. They do not add a backend, availability engine, payment integration, map SDK, media host, or newsletter service.

<Badge content="Beta" color="info" /> **API maturity: Beta.**

## Components

| Component | Purpose | Reference |
| --- | --- | --- |
| Video Section | Present native video, captions, playlists, carousels, and lightboxes. | [Video Section](/docs/pieces/components/video-section) |

| Location Section | Present addresses, contacts, locations, and an optional map slot. | [Location Section](/docs/pieces/components/location-section) |

## Integration boundaries

Use existing UI `Dialog`, `Carousel`, `DatePicker`, `TextInput`, and `Button`
primitives where they fit. Video autoplay respects muted playback and reduced
motion; locations use caller-provided map content; booking, waitlist, and
newsletter actions call application callbacks. Resource and event filtering
operate only on the supplied data.
