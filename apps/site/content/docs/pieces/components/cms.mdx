CMS authoring Pieces compose admin interfaces from data and actions supplied by the host application. They do not fetch, authorize, validate, schedule, or persist content. Use the `@puzzle-ui/cms` and `@puzzle-ui/fullstack/cms/*` APIs on the server and client for those responsibilities.

## Boundaries and integration

Install `@puzzle-ui/cms` when using the CMS family; its public types and field-type registry are used by the Pieces API. Components accept caller-owned content projections and callbacks. The host must authorize every operation, enforce tenant and revision checks, validate on the server, and use an explicit scheduler for scheduled publication.

Pass `ContentEditor.renderField` to compose specialized inputs such as `MediaField` or `RelationshipField`. Pass `BlockEditor.renderBlock` to edit the configured fields for each serializable block type. Advanced field settings belong to the CMS schema and server validation; `ContentTypeBuilder.renderFieldSettings` is the composition point for application-specific schema controls.

`PublishScheduler` converts local wall time using the selected timezone, reports nonexistent daylight-saving times, and chooses the earlier instant for an ambiguous repeated time. The server scheduler remains responsible for executing the returned publication job.
