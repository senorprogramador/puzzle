<code>@puzzle-ui/pieces</code> provides composed interface sections built on Puzzle UI. Use the existing Hero layouts for page introductions and the Marketing & Conversion collection for product features, customer proof, FAQs, comparisons, and calls to action. Pieces is not a general-purpose page builder or a library of complete website templates.

The package documents **48 section families** across seven categories. Use
the overviews below to compare their use cases, then open a component
reference for its full API and variant previews.

## Start with a Hero

Import the generic `Hero` component when you want to provide your own content and actions. The API also includes layout and visual presets such as `SplitHero`, `CenteredHero`, `ProductHero`, and `CampaignHero`.

```tsx
import { Button } from "@puzzle-ui/ui";
import { Hero } from "@puzzle-ui/pieces";

export function ProductIntroduction() {
  return (
    <Hero
      eyebrow="Product"
      title="A clear introduction to your page."
      description="Pair a concise message with a primary next step."
      actions={<Button href="/docs/getting-started">Get started</Button>}
    />
  );
}
```

The generic component supports different layouts, content alignment, and optional media. Browse the [Hero reference](/docs/pieces/components/hero) for available layouts, presets, and examples.

## Compose, do not replace

Pieces supplies larger sections, while [`@puzzle-ui/ui`](/docs/ui) provides the underlying components and [`@puzzle-ui/theme`](/docs/theme) provides design tokens and theme behavior. You can use a Hero on a page and compose the rest of the interface from those building blocks.

## API maturity

The documented Hero component and presets have **Stable** APIs, with
backward-compatibility intent within a major version. This describes API
maturity, not production readiness. Check the
[Hero API reference](/docs/pieces/components/hero) for supported props and
review the [API maturity guide](/docs/tutorials#api-maturity).
