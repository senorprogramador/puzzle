<code>@puzzle-ui/create</code> is an interactive command-line generator for new Puzzle applications. It scaffolds a project, configures the Puzzle theme, and can add Tailwind CSS and Puzzle Auth. For a guided walkthrough, see [Create a Project](/docs/developer/create-project).

## Install

The package is a CLI; run it with your package manager rather than adding it as a project dependency.

<PackageManagerTabs>
  <PackageManagerTab value="npm">

```bash
npx @puzzle-ui/create
```

  </PackageManagerTab>
  <PackageManagerTab value="bun">

```bash
bunx @puzzle-ui/create
```

  </PackageManagerTab>
  <PackageManagerTab value="pnpm">

```bash
pnpm dlx @puzzle-ui/create
```

  </PackageManagerTab>
  <PackageManagerTab value="yarn">

```bash
yarn dlx @puzzle-ui/create
```

  </PackageManagerTab>
</PackageManagerTabs>

Yarn's <code>dlx</code> command requires Yarn 2 or later; with Yarn Classic, use <code>npx @puzzle-ui/create</code>. The CLI requires Node.js 20.19 or later, one of npm, Bun, pnpm, or Yarn, and an internet connection to fetch framework templates and dependencies.

## Quick start

Run the generator, answer the prompts, then change into the generated directory and start the dev server. The remaining sections describe the available choices and generated files.

## Interactive setup

The CLI asks four questions. It has no command-line flags; setup is configured through these prompts.

| Prompt | Type | Default | Description |
| --- | --- | --- | --- |
| Project name | Text | None (placeholder: `my-awesome-app`) | Required; converted to kebab-case for the directory and package name. |
| Framework | Selection | None | Choose Basic React, TanStack Start, or Next.js. |
| Install Tailwind CSS? | Confirmation | Yes | Optionally add Tailwind CSS v4 and its framework integration. |
| Add Puzzle Auth? | Confirmation | No | Optionally add the Puzzle Auth client and, for full-stack frameworks, server integration. |

Canceling a prompt cancels project creation. The CLI refuses to create a project if the target directory already exists; it does not overwrite existing files.

## Frameworks and generated structure

Next.js and TanStack Start projects are generated with their respective official CLIs. Basic React is generated by Puzzle using React 19, Vite, and TypeScript. The framework generator may supply additional files; the paths below are the Puzzle-specific starter files and configuration.

| Selection | Starter files and configuration |
| --- | --- |
| **Next.js** — Next.js App Router | `src/app/providers.tsx`, `src/app/layout.tsx`, `src/app/page.tsx`, and `next.config.ts`. The starter page uses `Button`; the root layout applies `Theme` with system color mode. |
| **TanStack Start** — full-stack React | `src/routes/__root.tsx`, `src/routes/index.tsx`, and `vite.config.ts`. The root route applies `Theme` with system color mode; the starter route uses `Button`. |
| **Basic React** — React + Vite + TypeScript | `index.html`, `src/main.tsx`, `src/App.tsx`, `src/index.css`, `vite.config.ts`, and `tsconfig.json` with app and node configs. The entry point applies `Theme`; the starter app uses `Button`. |

The CLI updates the generated `package.json` name, configures framework package transpilation where needed, and installs `@puzzle-ui/ui` and `@puzzle-ui/theme` using the detected package manager. It detects npm, Bun, pnpm, or Yarn from the package-manager environment; if detection is unavailable, it uses npm.

## Tailwind CSS

Tailwind is enabled by default, but you can opt out. When enabled, the generator installs Tailwind CSS v4 as a development dependency and configures the integration:

| Framework | Configuration |
| --- | --- |
| Next.js | Adds `@import "tailwindcss";` to `src/app/globals.css` and configures `postcss.config.mjs` with `@tailwindcss/postcss`. |
| TanStack Start | Adds the Tailwind import to the stylesheet used by the root route, configures the `@tailwindcss/vite` plugin, and preserves the Puzzle packages in the SSR `noExternal` configuration. |
| Basic React | Adds the Tailwind import to `src/index.css` and configures the `@tailwindcss/vite` plugin. |

The CLI installs `tailwindcss`, `@tailwindcss/postcss`, and `postcss` for Next.js; for TanStack Start and Basic React it installs `tailwindcss` and `@tailwindcss/vite`.

## Puzzle Auth

Puzzle Auth is off by default. When enabled, the CLI installs `@puzzle-ui/auth`, `@puzzle-ui/fullstack`, and `@puzzle-ui/session`, adds an `AuthProvider` with the `/api/auth` base path, and creates sign-in and sign-up views using `AuthExperience`.

| Framework | Additional files |
| --- | --- |
| Next.js | `src/app/sign-in/page.tsx`, `src/app/sign-up/page.tsx`, `src/app/api/auth/[...auth]/route.ts`, and server-only modules under `src/lib/auth/` for server registration, bootstrap, and the unconfigured response. |
| TanStack Start | `src/routes/sign-in.tsx`, `src/routes/sign-up.tsx`, `src/routes/api/auth/$.ts`, and server-only modules under `src/lib/auth/` for server registration, bootstrap, and the unconfigured response. |
| Basic React | `src/auth/sign-in.tsx` and `src/auth/sign-up.tsx`. Basic React has no server runtime or API route; host the authentication API separately and configure the client base path for it. |

<Callout type="warn" title="Configure the server before using authentication">
  The generated server bootstrap is intentionally incomplete. Puzzle Auth needs
  application-provided storage and security dependencies, including a password
  hasher, rate limiter, session manager, MFA and step-up managers, cookie and
  CSRF configuration, and trusted client IP resolution. Until your application
  registers an <code>AuthServer</code>, the generated full-stack API route
  returns HTTP 503. See the [Authentication setup guide](/docs/developer/authentication).
</Callout>

## Run your application

After generation and dependency installation complete, run the development script in the new project directory with the selected package manager. For example:

```bash
cd my-awesome-app
npm run dev
```

## CLI package details

The package requires Node.js `>=20.19.0` and publishes one executable, `create-puzzle`, at `./dist/index.js`. It does not expose a JavaScript import API or package subpaths. The executable takes no flags; it always starts the interactive setup.
