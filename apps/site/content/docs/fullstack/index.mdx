title: Fullstack integrations
description: Connect Puzzle Auth, Media, CMS, and payment services to browser clients, server handlers, and Next.js or TanStack Start adapters.
---

`@puzzle-ui/fullstack` connects Puzzle Auth, Media, CMS, and commerce services to browser
applications and server routes. Its explicit subpaths separate browser-safe
clients, serializable shared contracts, server handlers, and Next.js/TanStack
Start adapters. The package complements `@puzzle-ui/auth`, `@puzzle-ui/session`,
`@puzzle-ui/media`, and `@puzzle-ui/cms`; it does not replace those domain
packages.

The existing Auth APIs, including the React components on
[Client and React](/docs/fullstack/client), are Stable with within-major
backward-compatibility intent. The Media and CMS subpaths are published, but
remain outside that maturity label and may lag the repository's current
workspace version.

## Install

server/client setup, required MFA enrollment, protected routes and logout.

React and React DOM 19 are required peer dependencies. The `next` and `@tanstack/react-start` peers are optional; install the framework you use to enable its adapter. For server setup, your app will also use `@puzzle-ui/auth`, `@puzzle-ui/session`, and a configured storage backend. See [Auth](/docs/auth), [Storage](/docs/storage), and the [authentication implementation guide](/docs/developer/authentication) for the service and persistence layers.

## Quick start

Wrap the client application in `AuthProvider`. It creates a client using `/api/auth` by default and loads the authentication snapshot from the server.

```tsx
import { AuthProvider } from "@puzzle-ui/fullstack/auth/client";

export const Providers = ({ children }: { children: React.ReactNode }) => (
  <AuthProvider>{children}</AuthProvider>
);
```

Create and configure an `AuthServer` from your server-side auth and session managers, then connect it to framework routes. The adapters and exact setup are covered in the pages below.

## What the package provides

| Area | Description | Documentation |
| --- | --- | --- |
| Client and React UI | Browser client, provider and hooks, authentication forms, MFA settings, and configurable sign-in/sign-up experience. | [Client and React](/docs/fullstack/client) |
| Server handlers | Authentication, MFA, sessions, lifecycle, route map, readiness checks, and step-up helpers. | [Server handlers](/docs/fullstack/server) |
| Media client and API | Browser-safe uploads, sanitized media views, server authorization, and upload lifecycle handlers. | [Media API](/docs/fullstack/media) |
| CMS client and API | Typed content, revision, publishing, localization, and relationship APIs with separate public reads. | [CMS API](/docs/fullstack/cms) |
| Next.js adapter | `GET` and `POST` handlers for a Next.js route handler. | [Next.js](/docs/fullstack/next) |
| TanStack Start adapter | A Request dispatcher or explicit route map for TanStack Start. | [TanStack Start](/docs/fullstack/tanstack) |
| Auth shared contracts | Serializable auth snapshots, inputs, and result types shared across runtimes. | [Auth shared types](/docs/fullstack/shared) |
| Payments | Server-only order total resolution, payment lifecycle orchestration, idempotency, refunds, and verified webhook processing. | [Commerce and payments](/docs/commerce), [Payment providers](/docs/payment-providers) |

## Package entry points

| Import | Use |
| --- | --- |
| `@puzzle-ui/fullstack/auth/client` | Browser client, React provider, hooks, UI, localization helpers, and passkey browser helpers. |
| `@puzzle-ui/fullstack/auth/server` | Server construction, route map, request/session helpers, MFA and lifecycle handlers, and readiness checks. |
| `@puzzle-ui/fullstack/auth/shared` | Shared TypeScript data contracts only; no runtime values. |
| `@puzzle-ui/fullstack/auth/next` | Next.js route-handler adapter. |
| `@puzzle-ui/fullstack/auth/tanstack` | TanStack Start request-handler adapter. |
| `@puzzle-ui/fullstack/media/client` | Browser media client and bounded upload queue. |
| `@puzzle-ui/fullstack/media/shared` | Serializable media API contracts and sanitized asset/folder views. |
| `@puzzle-ui/fullstack/media/server` | Authorized server handlers and route map. |
| `@puzzle-ui/fullstack/media/next` | Next.js media route-handler adapter. |
| `@puzzle-ui/fullstack/media/tanstack` | TanStack Start media dispatcher. |
| `@puzzle-ui/fullstack/cms/client` | Browser CMS client and query invalidation hooks. |
| `@puzzle-ui/fullstack/cms/shared` | Serializable CMS API contracts. |
| `@puzzle-ui/fullstack/cms/server` | Authorized CMS admin and published-content handlers. |
| `@puzzle-ui/fullstack/cms/next` | Next.js CMS route-handler adapter. |
| `@puzzle-ui/fullstack/cms/tanstack` | TanStack Start CMS dispatcher. |
| `@puzzle-ui/fullstack/payments/shared` | Serializable payment request and response contracts. |
| `@puzzle-ui/fullstack/payments/server` | Server-only payment orchestration, idempotency, refunds, and webhook processing. |

There is no package-root import; use one of the exported subpaths above. Keep auth policy and storage configuration in the appropriate lower-level packages, and use Fullstack to connect them to your app. For the end-to-end app setup, continue with the [developer authentication guide](/docs/developer/authentication).

Use [Puzzle UI](/docs/ui) and [Puzzle Theme](/docs/theme) for the rest of the
application interface; Fullstack's auth experience components can be composed
with either package.
