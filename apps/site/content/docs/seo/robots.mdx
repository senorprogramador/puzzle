## Quick start

```ts
import { generateRobotsTxt } from "@puzzle-ui/seo/robots";

const result = generateRobotsTxt({
  rules: [{ userAgent: "*", allow: ["/"], disallow: ["/admin/"] }],
  sitemap: "https://example.com/sitemap.xml",
});
if (result.issues.length) throw new Error(result.issues.map((issue) => issue.message).join("\n"));
const text = result.content;
```

## Options

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `rules` | `RobotsRule[]` | required | Groups of crawler rules. |
| `sitemap` | `string \| string[]` | — | Sitemap URL or URLs. |
| `host` | `string` | — | Optional host directive. |

Each `RobotsRule` requires `userAgent` as a string or string array and optionally accepts `allow`, `disallow` (arrays of paths), and numeric `crawlDelay`. `validateRobotsOptions` reports issues; `serializeRobotsTxt` returns text; `generateRobotsTxt` returns both text and issues. The [server handlers](/docs/seo/frameworks) turn invalid generation into a 500 response.

Robots rules are crawler instructions, not access control. Protect private resources with authentication and authorization. Page-level robots meta directives are separate; see [Metadata and URLs](/docs/seo/metadata).

## Exports

`@puzzle-ui/seo/robots` exports `validateRobotsOptions`, `serializeRobotsTxt`, `generateRobotsTxt` and the `RobotsDirective`, `RobotsRule`, `RobotsOptions`, `RobotsPolicy`, `RobotsResult`, and `RobotsValidationIssue` types.
