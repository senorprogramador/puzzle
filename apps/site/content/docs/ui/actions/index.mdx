Action components make commands and selections understandable without taking
ownership of application state. Use Button for an action or destination, and
use a toggle group when people choose one or more options from a known set.

## When to use action components

Use this category for controls that trigger an operation or change a selected
option. Keep navigation as links, and use form controls when collecting values
that are submitted as part of a form.

## Start here

- [Button](/docs/ui/actions/button) for an action or a destination.
- [Button Group](/docs/ui/actions/button-group) to visually group related

- [Toggle Group](/docs/ui/actions/toggle-group) for selecting one or more
