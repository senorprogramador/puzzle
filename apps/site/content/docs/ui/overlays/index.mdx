Overlay components place supporting or time-sensitive content above or beside
the current view. Puzzle includes modal, anchored, menu, and transient
patterns; select according to how much attention the content needs and whether
it blocks the underlying page.

## When to use overlays

Use a Dialog for a task that needs focused modal attention, and an anchored
Popover or Tooltip for brief contextual content. Prefer inline content when it
does not need to interrupt or overlay the current task.
