Layout components arrange content into page regions and responsive groups.
They provide composable building blocks for application shells, sections,
collections, and media without requiring a routing framework.

## When to use layout components

Use these primitives to express spatial relationships and responsive behavior.
Choose a page layout or sidebar for major regions, and a grid or stack for
smaller collections. Use the [Pieces](/docs/pieces) package when you need a
complete website section rather than a layout primitive.
