import { AspectRatio, Background, Badge, Heading, Preview, Stack } from "@puzzle-ui/ui";

Use the React Background component to add decorative patterns behind page content or a hero section. Patterns follow the active theme; keep the foreground readable and provide meaning through real content rather than decoration.

<Badge content="Stable" color="primary" /> **API maturity: Stable.** The documented public API is covered by tests and is intended to remain backward-compatible within a major version. This is an API commitment, not a guarantee of production readiness in every application.


## Import

```tsx
import { AspectRatio, Background, Heading, Stack } from "@puzzle-ui/ui";
```

## Patterns

Use backgrounds behind real content rather than as the only way to communicate meaning.
`Background` takes its size from its content or container. Here, `AspectRatio`
reserves a full-width square (`ratio={1}`). Keep foreground containers
transparent so they do not cover the decorative pattern.

## API

| Prop                              | Type                                                                                                                  | Default       | Description                            |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------- | ------------- | -------------------------------------- |
| `as`                              | `ElementType`                                                                                                         | `"div"`       | Semantic root element.                 |
| `pattern`                         | `"grid" \| "dots" \| "checkerboard" \| "stripes" \| "crosshatch" \| "glow" \| "blueprint" \| "topographic" \| "mesh"` | `"grid"`      | Decorative pattern.                    |
| `size`                            | `number \| string`                                                                                                    | `24`          | Pattern cell size; numbers are pixels. |
| `majorSize`                       | `number \| string`                                                                                                    | -             | Major grid spacing.                    |
| `lineWidth`, `dotSize`            | `number \| string`                                                                                                    | `1`, `2`      | Pattern line/dot dimensions.           |
| `angle`                           | `number \| string`                                                                                                    | `45`          | Stripe angle; numbers are degrees.     |
| `patternColor`, `backgroundColor` | `string`                                                                                                              | Theme-derived | CSS colors; prefer theme variables.    |
| `patternOpacity`                  | `number`                                                                                                              | -             | Pattern opacity, clamped to 0-1.       |
| `meshColors`                      | `readonly [string, string, string, string]`                                                                           | Theme-derived | Four mesh colors.                      |
| `fade`                            | `"top" \| "right" \| "bottom" \| "left"`                                                                              | -             | Fade pattern toward an edge.           |
| `children`                        | `ReactNode`                                                                                                           | -             | Foreground content.                    |

Native props for the selected element, including `className` and `style`, are forwarded. Check foreground contrast when customizing colors.

## Accessibility and keyboard behavior

Use semantic content and provide accessible names for interactive controls. Native controls retain browser keyboard behavior; any custom interaction should be verified with a keyboard and assistive technology in your application. This API maturity label is not an accessibility certification.

**Framework compatibility:** The UI package declares React and React DOM 19 as peers. Components do not require a router; framework-specific and server-rendering compatibility are not guaranteed, so verify behavior in your target framework.
