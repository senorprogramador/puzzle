## API

| Prop                          | Type                                                                       | Default             | Description                                           |
| ----------------------------- | -------------------------------------------------------------------------- | ------------------- | ----------------------------------------------------- |
| `logo`                        | `ReactNode`                                                                | -                   | Brand content.                                        |
| `title`                       | `string`                                                                   | -                   | Application title.                                    |
| `logoHref`                    | `string`                                                                   | `"/"`               | Brand destination.                                    |
| `navigationItems`             | `{ label: string; href: string; current?: boolean; external?: boolean }[]` | `[]`                | Navigation links.                                     |
| `customNavigationItems`       | `T[]`                                                                      | -                   | Custom navigation data.                               |
| `renderCustomNavigationItems` | `(item: T, index: number) => ReactNode`                                    | -                   | Renderer for custom items.                            |
| `trailingComponents`          | `ReactNode`                                                                | -                   | Actions after navigation.                             |
| `sticky`                      | `boolean`                                                                  | `false`             | Sticky positioning and PageLayout offset integration. |
| `ariaLabel`                   | `string`                                                                   | `"Main navigation"` | Accessible navigation name.                           |
| `className`                   | `string`                                                                   | -                   | Root styling hook.                                    |

Use descriptive destinations and label icon-only actions. Place sticky bars in `PageLayout.Header` to scope their measured layout offset to that page. Make the header region itself sticky (`position: sticky; top: 0`) when it wraps the bar, so the wrapper does not limit its sticky travel.

## Keyboard behavior

Native controls retain browser keyboard behavior. Verify the component and its interactive content with a keyboard in your application; the API maturity label is not an accessibility certification.

**Framework compatibility:** The UI package declares React and React DOM 19 as peers. Components do not require a router; framework-specific and server-rendering compatibility are not guaranteed, so verify behavior in your target framework.
