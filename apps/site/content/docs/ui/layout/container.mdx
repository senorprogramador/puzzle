Use the React Container component to center content and keep page widths consistent with the active theme. Choose a prose, content, or full-width container without adding a card surface or section theme.

<Badge content="Stable" color="primary" /> **API maturity: Stable.** The documented public API is covered by tests and is intended to remain backward-compatible within a major version. This is an API commitment, not a guarantee of production readiness in every application.


## Import

```tsx
import { Container } from "@puzzle-ui/ui";
```

## Usage

Use Container for width constraints without introducing a surface or section theme.

The base `puzzle-container` class limits its maximum width to
`var(--puzzle-container-width, 80rem)`. Width preset classes override this limit
for content, prose, or full-width containers.

## API

| Prop        | Type          | Default | Description              |
| ----------- | ------------- | ------- | ------------------------ |
| `as`        | `ElementType` | `"div"` | Semantic root element.   |
| `children`  | `ReactNode`   | -       | Constrained content.     |
| `className` | `string`      | -       | Additional root classes. |

Native props and refs for the chosen element are forwarded. For theme backgrounds and vertical section spacing, use `Section`.

## Accessibility and keyboard behavior

Use semantic content and provide accessible names for interactive controls. Native controls retain browser keyboard behavior; any custom interaction should be verified with a keyboard and assistive technology in your application. This API maturity label is not an accessibility certification.

**Framework compatibility:** The UI package declares React and React DOM 19 as peers. Components do not require a router; framework-specific and server-rendering compatibility are not guaranteed, so verify behavior in your target framework.
