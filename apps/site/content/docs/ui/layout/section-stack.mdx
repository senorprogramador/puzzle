Use the React SectionStack component to coordinate adjacent page sections, such as landing-page content blocks. Matching section themes receive adjoining spacing, and optional dividers separate sections visually.

<Badge content="Stable" color="primary" /> **API maturity: Stable.** The documented public API is covered by tests and is intended to remain backward-compatible within a major version. This is an API commitment, not a guarantee of production readiness in every application.


## Import

```tsx
import { SectionStack, Section } from "@puzzle-ui/ui";
```

## Shared themes and dividers

Adjacent direct Sections with matching themes receive compact adjoining spacing. `divideY` adds dividers between sections.

<Preview
  hideDevices={true}
  code={`\
<SectionStack divideY>
  <Section><Heading level="headline3">Overview</Heading></Section>
  <Section><Text>A matching theme keeps spacing compact.</Text></Section>
  <Section theme="primary"><Text>A new theme starts a distinct section.</Text></Section>
</SectionStack>
`}
>
  <SectionStack divideY>
    <Section>
      <Heading level="headline3">Overview</Heading>
    </Section>
    <Section>
      <Text>A matching theme keeps spacing compact.</Text>
    </Section>
    <Section theme="primary">
      <Text>A new theme starts a distinct section.</Text>
    </Section>
  </SectionStack>
</Preview>

## API

| Prop        | Type        | Default  | Description                            |
| ----------- | ----------- | -------- | -------------------------------------- |
| `children`  | `ReactNode` | Required | Prefer direct Section children.        |
| `divideY`   | `boolean`   | -        | Add dividers after non-final sections. |
| `className` | `string`    | -        | Root class.                            |

Other children render unchanged, but interrupt same-theme adjacency. Wrapping a Section in another component prevents direct-child coordination.

## Accessibility and keyboard behavior

Use semantic content and provide accessible names for interactive controls. Native controls retain browser keyboard behavior; any custom interaction should be verified with a keyboard and assistive technology in your application. This API maturity label is not an accessibility certification.

**Framework compatibility:** The UI package declares React and React DOM 19 as peers. Components do not require a router; framework-specific and server-rendering compatibility are not guaranteed, so verify behavior in your target framework.
