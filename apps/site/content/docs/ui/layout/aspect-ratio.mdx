The AspectRatio component maintains a consistent width-to-height proportion for its content.

<Badge content="Beta" color="info" /> **API maturity: Beta.** This API is functional and validated but may evolve; this label does not guarantee production readiness.


It uses the native CSS aspect-ratio property, making it suitable for responsive media containers, image galleries, video embeds, and other layouts where predictable proportions are important.

## Import

```tsx
import { AspectRatio } from "@puzzle-ui/ui";
```

## Basic usage

By default, AspectRatio uses a square (1:1) ratio.

## Aspect ratios

Use the `ratio` prop to define the desired width-to-height proportion.

The ratio is expressed as a number. For example, `16 / 9` represents a widescreen aspect ratio, while `4 / 3` represents a traditional display ratio.

<Preview
  hideDevices={true}
  code={`\
<Stack gap="lg" style={{ width: "100%", maxWidth: "240px" }}>
  <AspectRatio ratio={16 / 9}>
    <div style={{ background: "var(--puzzle-color-primary)", display: "grid", placeItems: "center", color: "white" }}>
      16:9
    </div>
  </AspectRatio>

<AspectRatio ratio={4 / 3}>
  <div
    style={{
      background: "var(--puzzle-color-secondary)",
      display: "grid",
      placeItems: "center",
      color: "white",
    }}
  >
    4:3
  </div>
</AspectRatio>

  <AspectRatio ratio={21 / 9}>
    <div style={{ background: "var(--puzzle-color-accent)", display: "grid", placeItems: "center", color: "white" }}>
      21:9
    </div>
  </AspectRatio>
</Stack>
`}
>
  <Stack gap="lg" style={{ width: "100%", maxWidth: "240px" }}>
    <AspectRatio ratio={16 / 9}>
      <div style={{ background: "var(--puzzle-color-primary)", display: "grid", placeItems: "center", color: "white" }}>
        16:9
      </div>
    </AspectRatio>
    <AspectRatio ratio={4 / 3}>
      <div style={{ background: "var(--puzzle-color-secondary)", display: "grid", placeItems: "center", color: "white" }}>
        4:3
      </div>
    </AspectRatio>
    <AspectRatio ratio={21 / 9}>
      <div style={{ background: "var(--puzzle-color-accent)", display: "grid", placeItems: "center", color: "white" }}>
        21:9
      </div>

  </Stack>
</Preview>

The aspect ratio is maintained automatically as the container width changes.

## Images

AspectRatio is particularly useful for responsive images.

Combine it with `object-fit: cover` to fill the container while preserving the image's proportions.

<Preview
  code={`\
<AspectRatio ratio={16 / 9}>
  <img
    src="/images/landscape.jpg"
    alt="Landscape"
    style={{ objectFit: "cover" }}
  />
</AspectRatio>
`}
>
  <div style={{ width: "100%" }}>
    <AspectRatio ratio={16 / 9}>
      <div
        style={{
          background: "linear-gradient(135deg, #527b66, #b9c8a1)",
          display: "grid",
          placeItems: "center",
          color: "white",
          fontSize: "1.25rem",
        }}
      >
        Landscape image · 16:9
      </div>
    </AspectRatio>
  </div>
</Preview>

For square images, such as avatars or product thumbnails, use the default ratio.

## Custom elements

Use the `as` prop to change the underlying HTML element.

All native properties supported by the selected element are forwarded to the root element.

<Preview
  hideDevices={true}
  align="center"
  justify="center"
  code={`\
<AspectRatio
  as="section"
  ratio={4 / 3}
  className="media-section"
  aria-label="Media section"
>
  <div>
    Content
  </div>
</AspectRatio>
`}
>
  <div style={{ width: "100%", maxWidth: "280px" }}>
    <AspectRatio as="section" ratio={4 / 3} aria-label="Media section">
      <div
        style={{
          background: "var(--puzzle-color-surface)",
          border: "1px solid var(--puzzle-color-border)",
          display: "grid",
          placeItems: "center",
        }}
      >
        Custom section element
      </div>
    </AspectRatio>
  </div>
</Preview>

## API

### Props

| Prop        | Type            | Default | Description                                              |
| ----------- | --------------- | ------- | -------------------------------------------------------- |
| `ratio`     | `number`        | `1`     | Width-to-height ratio. Must be a positive finite number. |
| `as`        | `ElementType`   | `"div"` | HTML element or component used as the root.              |
| `className` | `string`        | —       | Additional CSS class names.                              |
| `style`     | `CSSProperties` | —       | Additional inline styles.                                |
| `children`  | `ReactNode`     | —       | Content displayed inside the aspect ratio container.     |

All other native props supported by the selected root element are forwarded.

### TypeScript types

```tsx
type AspectRatioProps<C extends ElementType = "div"> = AspectRatioOwnProps<C> &
  Omit<ComponentPropsWithRef<C>, keyof AspectRatioOwnProps<C> | "as">;
```

The component also exports `AspectRatioProps` for use in custom components and wrappers.

## Behavior

- The default ratio is `1`, producing a square container.
- The `ratio` prop accepts any positive finite number.
- Invalid ratios, including zero, negative values, `NaN`, and infinity, throw a `RangeError`.
- The component uses the native CSS aspect-ratio property.
- The container fills the available width of its parent.
- Direct children are positioned to fill the container.
- Custom styles and classes are supported.
- The component does not require JavaScript layout calculations or browser observers.

## Accessibility

AspectRatio is a layout primitive and does not introduce additional ARIA roles or keyboard interactions.

The underlying HTML element determines its semantics.

When displaying images:

- Always provide meaningful `alt` text for informative images.
- Use an empty `alt` attribute for purely decorative images.
- Avoid using CSS backgrounds for images that convey meaningful information.

When embedding videos or iframes, provide an accessible title and ensure that the embedded content remains usable with a keyboard.

**Framework compatibility:** The UI package declares React and React DOM 19 as peers. Components do not require a router; framework-specific and server-rendering compatibility are not guaranteed, so verify behavior in your target framework.
