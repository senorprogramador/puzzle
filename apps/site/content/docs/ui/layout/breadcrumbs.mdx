Use the React Breadcrumbs component to show a page's place in a navigation hierarchy and provide links back to its ancestors. Breadcrumb navigation supplements the site's primary navigation rather than replacing it.

<Badge content="Stable" color="primary" /> **API maturity: Stable.** The documented public API is covered by tests and is intended to remain backward-compatible within a major version. This is an API commitment, not a guarantee of production readiness in every application.


## Import

```tsx
import { Breadcrumbs } from "@puzzle-ui/ui";
```

## Hierarchy

Provide linked ancestors followed by a current-page item without `href`. The last item receives `aria-current="page"`.

<Preview
  hideDevices={true}
  code={`\
<Breadcrumbs items={[
  { label: "Home", href: "#home" },
  { label: "Projects", href: "#projects" },
  { label: "Puzzle" },
]} />
`}
>
  <Section>
    <Breadcrumbs
      items={[
        { label: "Home", href: "#home" },
        { label: "Projects", href: "#projects" },
        { label: "Puzzle" },
      ]}
    />
  </Section>
</Preview>

## API

| Prop         | Type                                               | Default         | Description                                  |
| ------------ | -------------------------------------------------- | --------------- | -------------------------------------------- |
| `items`      | `[...BreadcrumbLinkItem[], BreadcrumbCurrentItem]` | Required        | Linked ancestors and one final current item. |
| `aria-label` | `string`                                           | `"Breadcrumbs"` | Navigation landmark name.                    |

Each item has `label: ReactNode` and optional `leadingIcon: ReactNode`; ancestor items require `href: string`. Native nav attributes are forwarded. Use concise labels and keep the path meaningful on narrow screens.

## Accessibility and keyboard behavior

Use semantic content and provide accessible names for interactive controls. Native controls retain browser keyboard behavior; any custom interaction should be verified with a keyboard and assistive technology in your application. This API maturity label is not an accessibility certification.

**Framework compatibility:** The UI package declares React and React DOM 19 as peers. Components do not require a router; framework-specific and server-rendering compatibility are not guaranteed, so verify behavior in your target framework.
