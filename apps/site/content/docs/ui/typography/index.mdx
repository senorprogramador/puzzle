Typography components provide theme-aware text styles while letting you choose
the semantic HTML element appropriate to the page. Keep visual appearance and
document structure aligned for readable, well-organized content.

## When to use typography components

Use Heading for section and page headings, and Text for body or supporting
copy. Choose heading levels from the document outline rather than from visual
size alone; use ordinary semantic HTML when a custom typography component
does not add value.
