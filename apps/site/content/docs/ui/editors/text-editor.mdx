import { Badge, Preview, TextEditor, TextEditorToolbar } from "@puzzle-ui/ui";

Use `TextEditor` for rich text editing in React, `TextEditorToolbar` to
provide formatting controls, and `TextRenderer` to display the saved document
without editing controls. Content is stored as a serializable `TextDocument`.

<Badge content="Stable" color="primary" /> **API maturity: Stable.** The documented public API is covered by tests and is intended to remain backward-compatible within a major version. This is an API commitment, not a guarantee of production readiness in every application.

## Import

```tsx
import { TextEditor, TextEditorToolbar, TextRenderer } from "@puzzle-ui/ui";
import type { TextDocument } from "@puzzle-ui/ui";
```

## Basic usage

Pass `defaultValue` for an uncontrolled editor and place the toolbar in the
`toolbar` prop so it receives the editor's formatting context.

        type: "doc",

            type: "paragraph",

For controlled editing, pass `value` and update it from `onChange`. Structurally
equal updates preserve the current selection; a changed external document starts
at the beginning and clears the editor history.

```tsx
const [document, setDocument] = useState<TextDocument>({
  type: "doc",
  content: [],
});

<TextEditor
  value={document}
  onChange={setDocument}
  toolbar={<TextEditorToolbar />}
/>;
```

## Display a document

```tsx
<TextRenderer document={document} />
```

Documents support paragraphs, headings, and list items with theme typography
variants. Inline marks include bold, italic, underline, and strike. Select text
and use the Link toolbar button to open a popover and add or edit a URL for
the selection; choose Remove link to remove the link while keeping its text.
The Link button is disabled when no text is selected, including when the cursor
is inside a link. Pressing Enter in an empty list item
exits the list. Links accept relative URLs and the `http`, `https`, `mailto`, or
`tel` schemes; unsafe schemes are discarded. `TextRenderer` renders text with
semantic elements rather than inserting raw HTML.

## API reference

### TextEditor

| Prop           | Type                               | Description                                                                                                                 |
| -------------- | ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `value`        | `TextDocument`                     | Controlled document. Structurally equal updates preserve selection; changed external documents reset selection and history. |
| `defaultValue` | `TextDocument`                     | Initial uncontrolled document.                                                                                              |
| `onChange`     | `(document: TextDocument) => void` | Called when the document changes.                                                                                           |
| `toolbar`      | `ReactNode`                        | Optional toolbar rendered in the editor context.                                                                            |

### TextEditorToolbar

| Prop        | Type             | Default             | Description                        |
| ----------- | ---------------- | ------------------- | ---------------------------------- |
| `className` | `string`         | -                   | Additional toolbar classes.        |
| `ariaLabel` | `string`         | `"Text formatting"` | Accessible toolbar name.           |
| `dir`       | `"ltr" \| "rtl"` | `"ltr"`             | Direction for keyboard navigation. |

### TextRenderer

| Prop        | Type           | Description                    |
| ----------- | -------------- | ------------------------------ |
| `document`  | `TextDocument` | Document to display. Required. |
| `className` | `string`       | Additional renderer classes.   |

## Accessibility

The formatting toolbar uses labeled buttons, pressed states, and arrow-key
navigation. Keep it inside the editor's `toolbar` prop and provide an
`ariaLabel` when multiple formatting toolbars need distinct names.

**Framework compatibility:** `TextEditor` is a client component and does not
depend on a router. `TextRenderer` can render saved documents without editing
controls. Package tests do not include full Next.js or TanStack Start
SSR/hydration integration, so verify those integrations in the consuming app.
