The editor category contains a JSON source editor and a rich-text editor. They
support distinct serialized formats and should not be used interchangeably.

## When to use an editor

Use `JsonEditor` to edit serialized JSON with caller-provided validation. Use
`TextEditor` when people need formatting controls for authored content. For
ordinary plain text fields, prefer the smaller controls in
[Forms](/docs/ui/forms); for displaying authored content, use a display
component instead.
