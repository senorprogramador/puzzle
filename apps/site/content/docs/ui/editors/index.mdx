The editor category currently contains Puzzle's rich-text editor. It is
intended for authoring formatted content, rather than ordinary single-line or
multi-line form input.

## When to use an editor

Use the text editor when people need formatting controls for authored content.
For plain text fields, prefer the smaller controls in [Forms](/docs/ui/forms);
for displaying already-authored content, use a display component instead.
