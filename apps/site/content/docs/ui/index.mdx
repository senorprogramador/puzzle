<code>@puzzle-ui/ui</code> provides reusable React components for building
interfaces with consistent theme tokens, layout, and interaction patterns.
Use this index to find a component's examples, props, and accessibility guidance.

Most documented component APIs are **Beta**. Paper, Skeleton, Label, Background,
Breadcrumbs, Sidebar, and Backdrop are **Experimental** because their current
validation evidence is limited. These labels describe API maturity, not
production readiness. Review each component's documented accessibility and
framework limitations when integrating it.

## Getting started

Follow the [Getting Started guide](/docs/getting-started) for installation and
wrap your application in the [Theme provider](/docs/theme/theme-provider).
Import components from <code>@puzzle-ui/ui</code>:

```tsx
import { Theme } from "@puzzle-ui/theme";
import { Button, Stack, Text } from "@puzzle-ui/ui";

const App = () => (
  <Theme>
    <Stack direction="col" gap="sm">
      <Text>Build your interface with Puzzle.</Text>
      <Button>Get started</Button>
    </Stack>
  </Theme>
);
```

## Theming

Components consume shared CSS custom properties rather than defining a separate
theme system. See [Theme](/docs/theme) for an overview,
[Design Tokens](/docs/theme/tokens) for customization, and
[Colors](/docs/theme/colors) for light, dark, and scoped color schemes.

The UI package targets React 19 and React DOM 19 and does not require a router.
Framework-specific and server-rendering compatibility are not guaranteed.
Explore [React hooks](/docs/hooks), [icons](/docs/icons), and
[composed page sections](/docs/pieces/components/hero) elsewhere in the Puzzle
ecosystem.
