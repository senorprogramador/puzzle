## Import

```tsx
import { Link } from "@puzzle-ui/ui";
```

## Destinations and new tabs

Use Link for navigation and Button for actions. New-tab links automatically include `noopener noreferrer` while preserving supplied `rel` tokens.

## API

| Prop             | Type                      | Default  | Description                                     |
| ---------------- | ------------------------- | -------- | ----------------------------------------------- |
| `href`           | `string`                  | Required | Destination.                                    |
| `children`       | `ReactNode`               | -        | Descriptive link content.                       |
| `componentProps` | `Record<string, unknown>` | -        | Extra props for a theme-configured router link. |
| `target`, `rel`  | `string`                  | -        | Native link attributes with new-tab protection. |

Native anchor attributes and refs are forwarded. The theme can configure a link component and its destination prop; the core UI remains router-independent. Use `aria-current="page"` for the current route.

## Accessibility and keyboard behavior

Use semantic content and provide accessible names for interactive controls. Native controls retain browser keyboard behavior; any custom interaction should be verified with a keyboard and assistive technology in your application. This API maturity label is not an accessibility certification.

**Framework compatibility:** The UI package declares React and React DOM 19 as peers. Components do not require a router; framework-specific and server-rendering compatibility are not guaranteed, so verify behavior in your target framework.
