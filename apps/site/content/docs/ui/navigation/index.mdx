Navigation components help people move between destinations or related views.
Puzzle provides router-independent links alongside controls for browsing
collections and switching among content.

## When to use navigation components

Use a Link for navigation to another URL. Use Tabs to switch among related
panels in the current context, and Pagination when a collection is divided into
pages. For actions that change data rather than navigate, choose an
[action component](/docs/ui/actions).
