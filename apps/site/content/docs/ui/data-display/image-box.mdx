ImageBox creates a responsive React image collage and chooses its layout from the number of images, including a balanced half-width split for five or more photos. Use it for a property listing, product detail, or portfolio preview. Use [Image](/docs/ui/data-display/image) for a single image with loading controls, or a dedicated image gallery when visitors need browsing controls such as a carousel, thumbnails, or zoom.

## Import

```tsx
import { ImageBox, type ImageBoxImage } from "@puzzle-ui/ui";
```

## Basic usage

Provide an image source and meaningful alternative text for each photo. The main image is loaded eagerly; supporting images are lazy-loaded.

```tsx
const photos: ImageBoxImage[] = [
  {
    src: "/stay/living-room.jpg",
    alt: "Living room with a view of the garden",
  },
  { src: "/stay/bedroom.jpg", alt: "Bedroom with a king-size bed" },
  { src: "/stay/kitchen.jpg", alt: "Kitchen with a marble island" },
  { src: "/stay/bathroom.jpg", alt: "Bathroom with a walk-in shower" },
  { src: "/stay/terrace.jpg", alt: "Private terrace with outdoor seating" },
  { src: "/stay/dining-room.jpg", alt: "Dining table beside a large window" },
  { src: "/stay/reading-nook.jpg", alt: "Reading chair beside a floor lamp" },
  { src: "/stay/garden.jpg", alt: "Garden surrounding the accommodation" },
  { src: "/stay/pool.jpg", alt: "Swimming pool with sun loungers" },
  { src: "/stay/exterior.jpg", alt: "Exterior of the accommodation at sunset" },
];

<ImageBox images={photos} />;
```

The sample collection below is used for the live layout previews.

## Geometry and spacing

For three or four images, the main image takes two-thirds of the content width and the supporting column takes one-third, excluding the gap. For five or more images, the main and supporting columns each take half of the content width, excluding the gap. In every collage layout, both columns share one fixed-height grid row. Supporting tracks use equal fractional rows (or a two-by-two grid), so their combined height including gaps exactly matches the main image.

The single `gap` value applies in both directions. The default uses the Puzzle spacing token and is slightly reduced at tablet widths. `aspectRatio` controls the collage's width-to-height ratio; every image uses `object-fit: cover` to fill its cell without changing the grid geometry.

<Preview

## Overflow and view-all action

The fifth photo remains visible under the overlay. The visible counter reports the number of additional photos (`total - 5`). Add `onViewAll` to make the overlay a native button and open your own gallery. On mobile, a compact count button appears on the main photo for collections of three or more.

## Responsive behavior

At desktop (1024px and wider) and tablet (640–1023px), the collage layout stays intact. Below 640px, collections of three or more show the main image across the full width and expose the total count. Supply `onViewAll` to make that count an action to the complete gallery; one- and two-image layouts remain unchanged.

## Interactions

When `onImageClick` is provided, each visible photo is a native button. The callback receives the original image object and its zero-based index. `onViewAll` is called only by the view-all overlay; it does not trigger `onImageClick`. Without callbacks, photos and counters do not pretend to be interactive.

```tsx
<ImageBox
  images={photos}
  onImageClick={(image, index) => openGalleryAt(index, image)}
  onViewAll={() => openGallery(0)}
/>
```

## API reference

### `ImageBoxImage`

| Property | Type     | Required | Description                                                                             |
| -------- | -------- | -------- | --------------------------------------------------------------------------------------- |
| `src`    | `string` | Yes      | Image URL. An empty value renders the image fallback.                                   |
| `alt`    | `string` | Yes      | Alternative text describing the image; use an empty string only for decorative imagery. |
| `title`  | `string` | No       | Optional native image title.                                                            |

### `ImageBoxProps`

| Property       | Type                                            | Default              | Required | Description                                                                                                      |
| -------------- | ----------------------------------------------- | -------------------- | -------- | ---------------------------------------------------------------------------------------------------------------- |
| `images`       | `ImageBoxImage[]`                               | —                    | Yes      | Images to arrange. Empty arrays render nothing; only five images are rendered at most.                           |
| `aspectRatio`  | `number`                                        | `2`                  | No       | Positive width-to-height ratio of the collage.                                                                   |
| `gap`          | `number \| string`                              | Puzzle spacing token | No       | Shared horizontal and vertical gap. Numbers are interpreted as CSS pixels; strings may be CSS lengths or tokens. |
| `radius`       | `number \| string`                              | Large radius token   | No       | Outer corner radius. Numbers are interpreted as CSS pixels.                                                      |
| `className`    | `string`                                        | —                    | No       | Class added to the collage container.                                                                            |
| `onImageClick` | `(image: ImageBoxImage, index: number) => void` | —                    | No       | Makes each visible image a button and receives that image and its zero-based index.                              |
| `onViewAll`    | `() => void`                                    | —                    | No       | Makes the overflow/mobile count overlay a button that opens the complete collection.                             |

## Accessibility

Write meaningful `alt` text for every image. The collage is exposed as a labeled group announcing the collection's total photo count. Interactive photos and view-all controls use native buttons, so Tab, Enter, and Space work without custom keyboard handlers; visible focus styling follows Puzzle's focus-ring token. The view-all name includes the total number of photos. On mobile, the count control is sized for touch. The component also supports forced-colors mode and avoids non-essential animation.

## Theming and styling

ImageBox uses Puzzle spacing, radius, typography, surface, and focus-ring tokens and follows the active light or dark theme. Use `gap`, `radius`, and `aspectRatio` for the supported layout controls, or add `className` to customize the outer wrapper. The underlying [Image](/docs/ui/data-display/image) component handles image loading and presents a neutral fallback for unavailable sources. Set a theme or scoped theme around ImageBox as usual; it does not introduce its own theme configuration.
