Use the React Paper component as a neutral surface when you need an elevated container without the structure of a [Card](/docs/ui/data-display/card). It separates supporting content from the page using theme-based surface styling.

<Badge content="Stable" color="primary" /> **API maturity: Stable.** The documented public API is covered by tests and is intended to remain backward-compatible within a major version. This is an API commitment, not a guarantee of production readiness in every application.


## Import

```tsx
import { Paper } from "@puzzle-ui/ui";
```

## Basic usage

Paper has no built-in padding, so add spacing yourself.

## Elevation

Use `elevation` to control the shadow depth. Available levels are `1`, `2`, `3`, `4`, `6`, `8`, `12`, `16`, and `24`. The default is `1`.

## Rendering a different element

Use `as` to render semantic HTML, such as `section` or `aside`.

```tsx
<Paper as="aside" aria-label="Tips">
  Remember to save your work.
</Paper>
```

## API reference

### Paper props

| Prop        | Type                                           | Default | Description                            |
| ----------- | ---------------------------------------------- | ------- | -------------------------------------- |
| `as`        | `ElementType`                                  | `"div"` | Element type used to render the paper. |
| `elevation` | `1 \| 2 \| 3 \| 4 \| 6 \| 8 \| 12 \| 16 \| 24` | `1`     | Shadow depth.                          |
| `className` | `string`                                       | —       | Additional CSS class names.            |
| `children`  | `ReactNode`                                    | —       | Content displayed inside the paper.    |

### Element props

Paper accepts the props of the element selected by `as`, passed through to it.

### TypeScript types

The component exports `PaperProps<C extends ElementType>`. The generic follows the element selected by `as`.

## Accessibility

Paper is purely presentational and adds no role or semantics. Choose a semantic element with `as` when the surface represents a landmark, and provide an accessible name where needed.

## Keyboard behavior

Native controls retain browser keyboard behavior. Verify the component and its interactive content with a keyboard in your application; the API maturity label is not an accessibility certification.

**Framework compatibility:** The UI package declares React and React DOM 19 as peers. Components do not require a router; framework-specific and server-rendering compatibility are not guaranteed, so verify behavior in your target framework.
