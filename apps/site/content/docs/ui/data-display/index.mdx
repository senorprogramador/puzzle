Data display components help people scan, compare, and understand information
without changing the underlying data. This category includes surfaces,
identity and status cues, tabular content, media, and loading or empty states.

## When to use data display components

Choose a component according to the shape of the information: use a table for
comparable rows and columns, a card for a grouped item, and an empty state when
there is no content to show. Use form controls when the user needs to edit or
submit a value.
