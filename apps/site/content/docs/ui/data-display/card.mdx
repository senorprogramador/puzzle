title: Card

Use the Card component to present a unit of related content, such as a summary, a product, or a settings group. Compose it from the Card parts to get consistent spacing and structure.

<Badge content="Beta" color="info" /> **API maturity: Beta.** This API is functional and validated but may evolve; this label does not guarantee production readiness.


## Import

```tsx
import {
  Card,
  CardHeader,
  CardTitle,
  CardDescription,
  CardAction,
  CardContent,
  CardFooter,
  CardMedia,
} from "@puzzle-ui/ui";
```

## Interactive cards

Set `interactive` to add hover and focus styling when the whole card is clickable. Render it as a link or button with `as` so it is keyboard accessible.

<Preview
  hideDevices={true}
  align="center"
  justify="center"
  code={`\
    <Card as="a" href="#" interactive style={{ width: 320 }}>
      <CardHeader>
        <CardTitle>Read the guide</CardTitle>
        <CardDescription>Everything you need to get started.</CardDescription>
      </CardHeader>
    </Card>
`}
>
  <Card as="a" href="#" interactive style={{ width: 320 }}>
    <CardHeader>
      <CardTitle>Read the guide</CardTitle>
      <CardDescription>Everything you need to get started.</CardDescription>
    </CardHeader>
  </Card>
</Preview>

When `interactive` is set without `as`, the card renders a `button` (or an `a` when `href` is passed) so it is keyboard operable. Do not combine `interactive` with `as="div"`: it only adds styling, not semantics.

## API reference

### Card props

| Prop          | Type                                              | Default      | Description                                       |
| ------------- | ------------------------------------------------- | ------------ | ------------------------------------------------- |
| `as`          | `ElementType`                                     | `"div"`      | Element type used to render the card.             |
| `variant`     | `"elevated" \| "outlined" \| "filled" \| "ghost"` | `"outlined"` | Surface style.                                    |
| `size`        | `"sm" \| "md" \| "lg"`                            | `"md"`       | Spacing scale.                                    |
| `orientation` | `"vertical" \| "horizontal"`                      | `"vertical"` | Direction in which the card's parts are laid out. |
| `interactive` | `boolean`                                         | `false`      | Adds hover and focus styling for clickable cards. |
| `className`   | `string`                                          | —            | Additional CSS class names.                       |
| `children`    | `ReactNode`                                       | —            | Card content.                                     |

### Card parts

| Component         | Default element | Purpose                                     |
| ----------------- | --------------- | ------------------------------------------- |
| `CardHeader`      | `div`           | Groups the title, description, and action.  |
| `CardTitle`       | `h3`            | Card heading. Change the level with `as`.   |
| `CardDescription` | `p`             | Supporting text for the title.              |
| `CardAction`      | `div`           | Control placed alongside the title.         |
| `CardContent`     | `div`           | Main body of the card.                      |
| `CardFooter`      | `div`           | Actions or metadata at the end of the card. |
| `CardMedia`       | `div`           | Image or other visual.                      |

Every part accepts `as`, `className`, `children`, and the props of the element it renders.

### Element props

Card accepts the props of the element selected by `as`, passed through to it.

### TypeScript types

The component exports `CardProps`, `CardPartProps`, `CardVariant`, `CardSize`, and `CardOrientation`.

## Accessibility

- `CardTitle` renders an `<h3>`. Use `as` to pick the level that fits the page's heading hierarchy.
- For a clickable card, render the card as `a` or `button` with `as` rather than adding a click handler to a `div`. Avoid nesting other interactive controls inside it.
- The card has no implicit role. Add `role`, `aria-labelledby`, or similar only when the card represents a meaningful landmark or group.

**Framework compatibility:** The UI package declares React and React DOM 19 as peers. Components do not require a router; framework-specific and server-rendering compatibility are not guaranteed, so verify behavior in your target framework.
