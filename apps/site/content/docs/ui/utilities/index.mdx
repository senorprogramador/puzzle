UI utilities support component composition and rendering behavior rather than
representing a particular content category. The available utilities document
preview rendering, SSR and deferred strategies, scroll locking, and transitions.

## When to use UI utilities

Use a utility when its documented behavior matches a specific rendering or
interaction need. Check the rendering guide before adding client-only
boundaries, and use scroll locking only when an overlay or equivalent
interaction requires it.
