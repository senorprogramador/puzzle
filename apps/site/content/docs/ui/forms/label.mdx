## Import

```tsx
import { Label } from "@puzzle-ui/ui";
```

## Usage

Match `htmlFor` to a control's `id`. Indicators are visual cues: configure `required` on the control itself as well. Prefer `FormField` when also displaying a description or error.

<Preview

  code={`\
<Stack>
  <Label htmlFor="label-name" required>Name</Label>
  <TextInput id="label-name" required />

</Stack>
`}

## API

| Prop       | Type        | Default  | Description                        |
| ---------- | ----------- | -------- | ---------------------------------- |
| `children` | `ReactNode` | Required | Visible label text.                |
| `htmlFor`  | `string`    | -        | Associated input ID.               |
| `required` | `boolean`   | `false`  | Adds a decorative required marker. |
| `optional` | `boolean`   | `false`  | Adds optional text.                |

Standard native label attributes, `className`, and `style` are supported.

## Accessibility and keyboard behavior

Use semantic content and provide accessible names for interactive controls. Native controls retain browser keyboard behavior; any custom interaction should be verified with a keyboard and assistive technology in your application. This API maturity label is not an accessibility certification.

**Framework compatibility:** The UI package declares React and React DOM 19 as peers. Components do not require a router; framework-specific and server-rendering compatibility are not guaranteed, so verify behavior in your target framework.
