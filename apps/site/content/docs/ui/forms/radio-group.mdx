## Import

```tsx
import { RadioGroup, Radio } from "@puzzle-ui/ui";
```

## Selection and orientation

Render `Radio` inside `RadioGroup`; every option needs a unique `value`. `name` enables native form submission and required validation.

## API

### RadioGroup

| Prop                   | Type                         | Default       | Description                            |
| ---------------------- | ---------------------------- | ------------- | -------------------------------------- |
| `children`             | `ReactNode`                  | Required      | Radio options.                         |
| `value`                | `string \| null`             | -             | Controlled selection; `null` is empty. |
| `defaultValue`         | `string`                     | -             | Initial uncontrolled selection.        |
| `onValueChange`        | `(value: string) => void`    | -             | Selected option value.                 |
| `label`, `description` | `ReactNode`                  | -             | Group legend and supporting text.      |
| `error`                | `ReactNode \| boolean`       | -             | Validation message.                    |
| `invalid`              | `boolean`                    | Error-derived | Explicit invalid state.                |
| `name`                 | `string`                     | -             | Shared native input name.              |
| `required`, `disabled` | `boolean`                    | `false`       | Group state.                           |
| `orientation`          | `"horizontal" \| "vertical"` | `"vertical"`  | Layout direction.                      |
| `size`                 | `"sm" \| "md" \| "lg"`       | `"md"`        | Option size.                           |
| `dir`                  | `"ltr" \| "rtl"`             | -             | Keyboard text direction.               |
| `loop`                 | `boolean`                    | `true`        | Wrap keyboard navigation.              |

### Radio

| Prop                | Type        | Default  | Description                 |
| ------------------- | ----------- | -------- | --------------------------- |
| `value`             | `string`    | Required | Unique option identifier.   |
| `label`, `children` | `ReactNode` | -        | Option label; `label` wins. |
| `description`       | `ReactNode` | -        | Option supporting text.     |
| `disabled`          | `boolean`   | `false`  | Disables this option.       |

Group props extend native fieldset attributes. Radio forwards supported input props and refs; `className`/`style` target its label. Arrow keys select enabled options; Home/End reach the boundaries.

## Accessibility and keyboard behavior

Use semantic content and provide accessible names for interactive controls. Native controls retain browser keyboard behavior; any custom interaction should be verified with a keyboard and assistive technology in your application. This API maturity label is not an accessibility certification.

**Framework compatibility:** The UI package declares React and React DOM 19 as peers. Components do not require a router; framework-specific and server-rendering compatibility are not guaranteed, so verify behavior in your target framework.
