Puzzle form components cover common value-entry patterns, from text and number
inputs to selectable options, repeatable fields, dates, files, image preparation,
video upload, and verification tokens. Compose them with labels, descriptions,
and validation feedback that fit the needs of your application.

## When to use form components

Use these controls when people need to enter or select values. Choose
Autocomplete when searching a larger option set, Select for a bounded list,
and text inputs for direct entry. Use `FieldArray` for repeatable or nested
entries while keeping values and business validation in the caller. Puzzle
supplies presentation and interaction primitives; your application remains
responsible for form state, validation rules, and submission.
