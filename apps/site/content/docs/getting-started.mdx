Puzzle is a TypeScript and React UI component library built around reusable components and shared design tokens. Its components are composable and router-independent, with styling supplied by <code>@puzzle-ui/theme</code>.

<Callout type="warn" title="Early development">
  Puzzle is under active development and is not ready for production use. APIs,
  props, exports, and styling may change without notice. Accessibility and
  framework compatibility are still being tested. Use the project for
  experimentation and evaluation.
</Callout>

## Prerequisites

- A package manager: npm, Bun, pnpm, or Yarn.
- An existing React application with a bundler that supports CSS imports, such as Vite.
- React and React DOM 19.

## Install Puzzle

Install the UI and theme packages in your application's directory.

<PackageManagerTabs>
  <PackageManagerTab value="npm">

```bash
npm install @puzzle-ui/ui @puzzle-ui/theme
```

  </PackageManagerTab>
  <PackageManagerTab value="bun">

```bash
bun add @puzzle-ui/ui @puzzle-ui/theme
```

  </PackageManagerTab>
  <PackageManagerTab value="pnpm">

```bash
pnpm add @puzzle-ui/ui @puzzle-ui/theme
```

  </PackageManagerTab>
  <PackageManagerTab value="yarn">

```bash
yarn add @puzzle-ui/ui @puzzle-ui/theme
```

  </PackageManagerTab>
</PackageManagerTabs>

These commands install published packages. They do not clone the repository or build its workspaces. Puzzle does not require Bun in your application.

## Your first interface

Import components from <code>@puzzle-ui/ui</code> and wrap your application in <code>Theme</code> from <code>@puzzle-ui/theme</code>.

```tsx
import { Theme } from "@puzzle-ui/theme";
import { Button } from "@puzzle-ui/ui";

export const App = () => (
  <Theme theme="system">
    <main>
      <h1>Hello, Puzzle</h1>
      <p>Build your interface with reusable components and shared tokens.</p>
      <Button onClick={() => window.alert("Welcome to Puzzle!")}>
        Get started
      </Button>
    </main>
  </Theme>
);
```

<code>Theme</code> applies the default tokens and global styles, and follows the
user's system light/dark preference. Use one root theme for your application.

Component styles are imported by the components themselves. Your application bundler must support CSS imports.

See [Button](/docs/ui/actions/button) for variants, sizes, and API details.

## Customize your theme

Set the color mode, choose a color palette, load fonts, or override individual tokens.

```tsx
<Theme
  theme="system"
  colorTheme="cobalt-sky"
  fonts={{
    heading: { family: "Inter" },
    body: { family: "Inter" },
  }}
  tokens={{
    radius: { md: "0.5rem" },
  }}
>
  <AppContent />
</Theme>
```

Font configuration can load stylesheets from Google Fonts. Omit <code>fonts</code> if you do not want external font requests.

In your own CSS, use the same semantic tokens as Puzzle components.

```css
.welcome-panel {
  color: var(--puzzle-color-text);
  background: var(--puzzle-color-surface);
  padding: var(--puzzle-space-4);
  border-radius: var(--puzzle-radius-md);
}
```

Read the [Theme overview](/docs/theme), [Theme Provider](/docs/theme/theme-provider), and [Design Tokens](/docs/theme/tokens) guides for configuration details.

## Build your application

Puzzle ships compiled JavaScript and CSS, so you do not need to build the library yourself. Use your application's existing build script.

<PackageManagerTabs>
  <PackageManagerTab value="npm">

```bash
npm run build
```

  </PackageManagerTab>
  <PackageManagerTab value="bun">

```bash
bun run build
```

  </PackageManagerTab>
  <PackageManagerTab value="pnpm">

```bash
pnpm run build
```

  </PackageManagerTab>
  <PackageManagerTab value="yarn">

```bash
yarn run build
```

  </PackageManagerTab>
</PackageManagerTabs>

Your application must retain CSS imports when bundling Puzzle. No separate Puzzle stylesheet import or Tailwind setup is required.

Framework and server-rendering compatibility is still being evaluated. Test your chosen components in your application's environment.
