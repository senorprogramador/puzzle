Puzzle is a TypeScript and React UI component library built around reusable components and shared design tokens. Its components are composable and router-independent, with styling supplied by `"@puzzle-ui/theme`. The framework is setup to be compatible with `Next.js`, `Tanstack Start` and `react-router`.

**Puzzle is under active development and is not ready for production use.** APIs, props, exports, and styling may change without notice. Accessibility and framework compatibility are still being tested. Use the project for experimentation and evaluation.

## Prerequisites

- A package manager: npm, Bun, pnpm, or Yarn.
- An existing React application with a bundler that supports CSS imports, such as Vite.
- Familiarity with React and TypeScript. The UI and theme packages require React and React DOM 19 or later within the supported React 19 range.

## Your first interface

Import components from `"@puzzle-ui/ui` and wrap your application in `Theme` from `"@puzzle-ui/theme`:

```tsx
import { Theme } from "@puzzle-ui/theme";
import { Button } from "@puzzle-ui/ui";

export const App = () => (
  <Theme>
    <main>
      <h1>Hello, Puzzle</h1>
      <p>Build your interface with reusable components and shared tokens.</p>
      <Button onClick={() => window.alert("Welcome to Puzzle!")}>
        Get started
      </Button>
    </main>
  </Theme>
);
```

`Theme` applies default tokens and global styles, and follows the user's system light/dark preference. Use one root theme for your application. Component styles are imported by the components themselves; your application bundler must support CSS imports, as the repository's Vite apps do.

## Customize your theme

Set the color mode, choose a color palette, load fonts, or override individual tokens:

```tsx
<Theme
  theme="system"
  colorTheme="cobalt-sky"
  fonts={{
    heading: { family: "Inter" },
    body: { family: "Inter" },
  }}
  tokens={{
    radius: { md: "0.5rem" },
  }}
>
  <AppContent />
</Theme>
```

Font configuration loads stylesheets from Google Fonts. Omit `fonts` if you do not want external font requests.

In your own CSS, use the same semantic tokens as Puzzle components:

```css
.welcome-panel {
  color: var(--puzzle-color-text);
  background: var(--puzzle-color-surface);
  padding: var(--puzzle-space-4);
  border-radius: var(--puzzle-radius-md);
}
```

Read the [Theme overview](/docs/theme), [Theme Provider](/docs/theme/theme-provider), and [Design Tokens](/docs/theme/tokens) guides for configuration details. Use [Component Overrides](/docs/theme/components) to integrate your router's link component or a framework image component.

## Build your application

Puzzle ships compiled JavaScript and CSS, so you do not need to build the library yourself. Use your app's `build` script to bundle it:

<PackageManagerTabs>
  <PackageManagerTab value="npm">```bash npm run build ```</PackageManagerTab>
  <PackageManagerTab value="bun">```bash bun run build ```</PackageManagerTab>
  <PackageManagerTab value="pnpm">```bash pnpm run build ```</PackageManagerTab>
  <PackageManagerTab value="yarn">```bash yarn run build ```</PackageManagerTab>
</PackageManagerTabs>

Your app must retain CSS imports when bundling Puzzle. No separate Puzzle stylesheet import or Tailwind setup is required. Framework and server-rendering compatibility is still being evaluated; test your chosen components in your application's environment.
